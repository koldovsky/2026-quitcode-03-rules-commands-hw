# refactor

**Ціль:** $ARGUMENTS
(Якщо в рядку вище немає конкретного файлу — ціль вказана в повідомленні одразу
після назви команди. Немає й там — спитай і зупинись.)

## Кроки

1. **Перевір ціль на захищеність.** Якщо шлях підпадає під будь-який із захищених
   у `.claude/rules/do-not-touch.md` — `app/src/core/**`, `app/scripts/**`,
   `materials/**`, `.coderabbit.yaml`, `.github/**` — **зупинись і відмов**. Не лише core.
2. Відкрий ціль інструментом Read (не через `cat`) — так підтягнуться правила з `paths`.
3. Зафіксуй стан **до**. Три команди, кожна окремо, статус кожної записуй
   незалежно — падіння однієї не скасовує решту:
   ```bash
   cd app && npm run check:rules      # скільки порушень саме в цільовому файлі
   cd app && npm test                 # скільки тестів і який результат
   cd app && npm run typecheck        # чисто чи ні
   ```
4. Випиши **інваріанти поведінки**, які не можна зачепити: URL запиту, тіло запиту,
   тексти помилок, значення, що повертаються. Далі звіряєшся саме з ними.
5. Приведи файл до конвенцій (`.claude/rules/conventions.md`). Типово це заміна
   прямого `fetch` на `postJson()`, `process.env` на `readEnv()`, `JSON.parse` на
   `parseJson()` з guard, `console.*` на `log`, `any` на `unknown` + guard.
6. Зафіксуй стан **після** тими самими трьома командами.
7. Покажи діф і поруч — таблицю до/після по трьох командах.

## Acceptance criteria

- [ ] Порушення `check:rules` для цільового файлу: було N → стало 0.
- [ ] `npm test` — та сама кількість тестів, усі зелені; **асерти наявних тестів не
      редаговані** (перевір `git diff` по тестових файлах).
- [ ] `npm run typecheck` чистий до і після.
- [ ] Інваріанти з кроку 4 не змінились: той самий URL, те саме тіло запиту, ті самі
      тексти помилок.
- [ ] Кожне число у звіті — з реального виводу команди, а не з пам'яті.

## Stop

Змінюй **лише цільовий файл**. Якщо через зміну сигнатури довелось торкнутись місць,
де його імпортують, — правиш лише імпорт і виклик, нічого більше; це називаєш у звіті.

Усе інше, що помітив (баги в сусідніх файлах, слабкі тести), — **списком у звіті без
правок**. Якщо конвенцію не виконати без зміни поведінки — зупинись, покажи конфлікт
і чекай рішення людини.
