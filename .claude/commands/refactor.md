# Рефакторинг до конвенцій

**Ціль:** $ARGUMENTS
(Якщо в рядку вище немає конкретного файлу — ціль вказана в повідомленні одразу
після назви команди. Немає й там — спитай і зупинись.)

## Кроки

1. Перевір ціль: файл існує, лежить в `app/src/` і **не** в `app/src/core/`
   (інакше — Stop за `.claude/rules/do-not-touch.md`).
2. Зніми базову лінію з теки `app/`: `npm test` (скільки тестів, чи зелені) і
   `npm run check:rules` (`TOTAL` і всі рядки для цього файлу). Запиши.
3. Прочитай файл, його тест (`<файл>.test.ts`), модулі, які він імпортує, і
   `.claude/rules/conventions.md`, `.claude/rules/architecture.md`.
4. Випиши поведінку, яку фіксують тести й контракт: URL, тіло запиту, тексти
   помилок, значення, що повертаються, `name`/`requiredEnv` інтеграції. Це не
   змінюється.
5. Виправ лише порушення конвенцій за правилами (`Result`, `postJson`, `readEnv`,
   `parseJson` + guard, `log`, без `any`). Не перейменовуй експорти, не змінюй
   публічні сигнатури, не «покращуй» логіку поза конвенціями.
6. Повтори з `app/`: `npm test`, `npm run typecheck`, `npm run check:rules`.
7. Покажи підсумок: таблиця до → після (`check:rules` для файлу, `TOTAL`, кількість
   тестів), список змінених файлів, що свідомо лишилось як було і чому.

## Acceptance criteria

- [ ] `check:rules` для цільового файлу: 0 порушень (або кожне залишене пояснено).
- [ ] `TOTAL` зменшився рівно на кількість виправлених порушень цього файлу.
- [ ] `npm test` зелений, кількість тестів не зменшилась; `npm run typecheck` зелений.
- [ ] Наявні асерти в тестах не змінені (нові тести додавати можна).
- [ ] Змінено лише цільовий файл і, за потреби, його `*.test.ts`; `core-untouched` — 0.

## Stop

- Лише цільовий файл і його імпорти — читати; змінювати — лише цільовий файл (і
  його тест, якщо додаєш нові випадки). Асерти наявних тестів не редагуй.
- Тест падає і виправити його можна лише зміною асерта або поведінки — зупинись,
  поверни файл як був і опиши, що саме конфліктує.
- Конвенцію не виконати без змін у core — зупинись і опиши потрібну зміну.
- Не комітить: покажи підсумок людині.
