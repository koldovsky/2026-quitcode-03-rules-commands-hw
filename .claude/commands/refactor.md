# refactor

**Ціль:** $ARGUMENTS
(Якщо в рядку вище немає конкретного файлу — ціль вказана в повідомленні одразу
після назви команди. Немає й там — спитай і зупинись.)

## Кроки

1. Зафіксуй стан **до**:
   ```bash
   cd app && npm test && npm run check:rules
   ```
   Випиши: кількість зелених тестів, `TOTAL`, і скільки порушень у розділі
   `by file` припадає саме на цільовий файл.
2. Прочитай цільовий файл і його тест поруч (`<ім'я>.test.ts`). Тест — це
   специфікація поведінки: URL, тіло запиту, тексти помилок.
3. Перепиши файл під `.claude/rules/conventions.md`: `fetch` → `postJson`,
   `process.env` → `readEnv`, `JSON.parse` → `parseJson` з guard, `console.*` → `log`,
   `any` → `unknown` + guard, типізуй за контрактом `Integration` з `core/types.js`.
4. **Поведінку не змінюй.** Незмінними лишаються: URL і спосіб його складання,
   форма тіла запиту, тексти повідомлень про помилку, значення, що повертаються,
   порядок викликів. Рефакторинг — це та сама поведінка іншим кодом.
5. Зафіксуй стан **після** тими самими двома командами. Порівняй числа.

## Acceptance criteria

- [ ] `cd app && npm test` — та сама кількість зелених тестів, що й до (18).
- [ ] `npm run check:rules` — порушень у цільовому файлі стало менше; `TOTAL` не зріс.
- [ ] `npm run typecheck` — чисто.
- [ ] `git diff --name-only` містить **лише** цільовий файл (і `integrations/index.ts`,
      якщо змінився спосіб експорту).
- [ ] `core-untouched 0`; `app/scripts/**` і `materials/**` не змінені.
- [ ] Показано таблицю «до → після» з числами.

## Stop

- Чіпай **лише вказаний файл**. Його імпорти — тільки читай.
- **Асерти в тестах не редагуй.** Якщо тест падає — падає рефакторинг, а не тест.
  Дозволено змінити лише спосіб підміни (`vi.stubGlobal`/`vi.stubEnv`), якщо
  модуль перейшов на `postJson`/`readEnv`; очікувані значення лишаються ті самі.
- Якщо привести файл до конвенцій без зміни `app/src/core/**` неможливо —
  зупинись за `.claude/rules/do-not-touch.md` і опиши, чого бракує в ядрі.
- Якщо конвенція вимагає змінити поведінку, яку фіксує тест, — зупинись, покажи
  конфлікт і чекай рішення людини.
