# generate-integration

**Ціль:** $ARGUMENTS
(Якщо в рядку вище немає назви сервісу — вона вказана в повідомленні одразу після
назви команди. Немає й там — спитай і зупинись.)

## Кроки

1. Прочитай інструментом Read `app/src/integrations/slack-notify.ts` і його тест —
   це зразок, що відповідає конвенціям. Разом з ними підтягнуться правила проєкту.
2. Визнач `kebab-name` сервісу. Створи рівно три зміни, як описано в
   `.claude/rules/architecture.md`:
   - `app/src/integrations/<kebab-name>.ts`
   - `app/src/integrations/<kebab-name>.test.ts`
   - один рядок у `app/src/integrations/index.ts`
3. Модуль пиши за конвенціями (`.claude/rules/conventions.md`). Додатково, з уроків
   нічного інциденту й вимог до секретів:
   - секрет **не вшивається в URL**, бо URL може потрапити в журнал; передавай
     секрет заголовком або в тілі запиту й не записуй його ні в журнал, ні в
     текст помилки;
   - перевір, що URL із `readEnv()` має схему `https:`; інакше — `Result` з `ok: false`;
   - для **неідемпотентних** POST (створення контакту, відправка повідомлення)
     став `retries: 0` у `PostOptions`: автоповтор створює дублікати;
   - якщо зовнішня система вміє upsert або віддає 409 на «вже існує» — оброби це
     як успіх, а не як помилку;
   - відповідь зовнішньої системи розбирай `parseJson(text, guard)` з guard на
     очікувану форму.
4. Тест поруч, три випадки мінімум: успішна відправка (звір URL і тіло запиту),
   відсутня змінна середовища, помилка від зовнішньої системи.
   `fetch` підміняй через `vi.stubGlobal`, змінні — через `vi.stubEnv`.
   В асертах не використовуй `JSON.parse` — порівнюй з `JSON.stringify(очікуване)`.
   Якщо перевіряєш журнал — шпигуй за `log.info` / `log.error`, а не за `console.*`.
5. Прогони й покажи вивід: `cd app && npm test && npm run typecheck && npm run check:rules`.

## Acceptance criteria

- [ ] Створено рівно два нових файли (`git status --short`), а в реєстрі змінено
      рівно один рядок — перевір `git diff --unified=0 -- app/src/integrations/index.ts`.
- [ ] `name` інтеграції дослівно збігається з іменем файлу; `requiredEnv` містить лише імена змінних.
- [ ] `send()` повертає `Result<void>` і не кидає винятків назовні.
- [ ] Жодного секрету в URL і в журналі; схема URL перевірена.
- [ ] `npm test` зелений, `npm run typecheck` чистий, `npm run check:rules` без нових порушень.
- [ ] Якщо інтеграція є сповіщенням — у тілі немає `lead.email` і `lead.phone`.

## Stop

`app/src/core/**` не чіпай — потрібного немає в публічному API ядра, значить діє
стоп-протокол з `.claude/rules/do-not-touch.md`. Нових залежностей не додавай:
`npm install` не запускати.

Наприкінці покажи підсумок: які файли створено, який рядок додано в реєстр, вивід
трьох команд — і зупинись.
