# Захищені зони

<!-- Правило без frontmatter `paths` — завантажується на старті кожної сесії. -->

## Контекст

`app/src/core/` належить платформній команді: той самий core працює в усіх
клієнтських воркерах агенції, і зміни в ньому йдуть окремим PR через рев'ю цієї
команди. Решта захищених шляхів — умови самого завдання й інфраструктура
перевірки. Джерело: `materials/architecture-brief.md`.

## Правило

**Не редагуй, не створюй, не видаляй і не перейменовуй файли в цих шляхах:**

- `app/src/core/**` — ядро платформи
- `app/scripts/**` — перевірка правил (`check-rules.mjs`, `core.lock.json`)
- `materials/**` — матеріали завдання
- `.coderabbit.yaml`
- `.github/**`

Це стосується будь-яких змін, зокрема тих, що здаються нешкідливими: коментар,
пробіл, «додам одне поле в інтерфейс», «допишу один тип», «дрібний фікс»,
форматування, оновлення імпорту.

**Заборонено обходити перевірку.** Не запускай `npm run check:rules -- --write-lock`
і не редагуй `app/scripts/core.lock.json`, щоб «узгодити» хеші після зміни core.
Це приховує зміну, а не скасовує її.

**Якщо задача не виконується без зміни ядра — зупинись.**

Не роби задачу частково, не обходь ядро копією його коду в `integrations/` чи
`sync/`, не розширюй типи через `declare module`, локальні `interface X extends Lead`
або приведення типів. Замість цього зупинись і видай людині:

1. що саме треба змінити в core — файл, рядок, конкретна правка;
2. навіщо — яку частину задачі без цього не зробити;
3. які частини задачі можна виконати вже зараз, без ядра;
4. запропонований варіант обхідного рішення поза core, якщо він існує, — і чим
   він гірший за зміну ядра.

Далі чекай рішення людини. Не продовжуй, доки його немає.

> Тут немає винятку «якщо задача цього потребує»: будь-яка задача оголосить, що
> потребує. Єдина дозволена реакція на таку потребу — зупинка й опис вище.

## Як перевірити

- `cd app && npm run check:rules` → у розділі `by rule` рядок `core-untouched  0`.
  Будь-яке `modified` / `added` / `deleted` у звіті — правило порушено.
- `git status --short` і `git diff --stat` не містять шляхів `app/src/core/`,
  `app/scripts/`, `materials/`, `.coderabbit.yaml`, `.github/`.
- `git diff --name-only app/scripts/core.lock.json` — порожній.
