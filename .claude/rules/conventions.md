# conventions

## Контекст

Частина коду прийшла з n8n-воркфлоу і не відповідає конвенціям: прямий
`fetch`, `console.log` із секретами, тихі значення за замовчуванням на
невалідних даних. Ці конвенції — щоб новий і змінений код такого не повторював.

## Правило

- Помилки — значення, не винятки: функції, що можуть не вдатись, повертають
  `Result<T>`; `send()` інтеграції завжди повертає `Result<void>` і не кидає
  винятків назовні.
- Вихідний HTTP — лише через `postJson()` з `app/src/core/http.ts`. Не
  використовуй `fetch` напряму в `integrations/` чи `sync/` (у ньому нема
  таймауту, повторів на 5xx/429 і маскування URL у журналі).
- Змінні середовища — лише через `readEnv()` з `app/src/core/config.ts`. Не
  читай `process.env` поза цим файлом. Секрети не пишуться в журнал і не
  вшиваються в код, навіть тимчасово.
- Будь-який зовнішній JSON (відповідь API, тіло вебхука, файл стану) — лише
  через `parseJson(text, guard)` з guard на очікувану форму. Невалідний JSON
  або неочікувана форма — це `Result` з `ok: false`, видимий у журналі; не
  підставляй тихе значення за замовчуванням.
- Журнал — лише через `log` з `app/src/core/log.ts`. Не використовуй
  `console.*` поза цим файлом.
- Без `any` — для невідомих даних `unknown` плюс guard.
- Без нових залежностей — у застосунку нуль runtime-залежностей, і так має
  лишитись. Потрібна бібліотека — питання в PR, а не `npm install`.
- У сповіщення (Slack, месенджери) не передавай email і телефон ліда — лише
  ім'я, джерело й бюджет. Повні дані — тільки в системах обліку (таблиця, CRM).
- Файли — kebab-case; поле `name` інтеграції збігається з іменем файлу.

## Як перевірити

- `cd app && npm run check:rules` → 0 попереджень.
- `grep -rn "console\." app/src/integrations app/src/sync` → порожньо.
- `grep -rn "fetch(" app/src/integrations app/src/sync` → порожньо (у самому
  коді; у тестах допустимо через `vi.stubGlobal("fetch", ...)`).
- `grep -rn ": any" app/src/**/*.ts` → порожньо.
- `cat app/package.json` → секція `dependencies` порожня (лише
  `devDependencies`).
- Ручний огляд тіла запиту в кожній інтеграції для Slack/месенджерів: полів
  `email` і `phone` там немає.
