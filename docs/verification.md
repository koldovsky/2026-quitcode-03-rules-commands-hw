# Перевірка (Task B, C і бонус E)

## Task B — чи бачить інструмент AGENTS.md

- Інструмент і версія: Claude Code 2.1.20 у VS Code, модель `claude-opus-4-5-20251101`
  (версія й модель — з журналу сесії; вікно `/status` закрилось без виводу).
- Як перевірив: нова сесія з кореня репо (21.09.2026) → `/context`, розділ
  **Memory files**; потім, не відкриваючи файлів, попросив перелічити правила в
  контексті; потім — прочитати `app/src/integrations/slack-notify.ts` і знову `/context`.
- Результат:
  - `/context` на старті сесії:
    ```
    Memory files · /memory
    └ CLAUDE.md: 177 tokens
    └ AGENTS.md: 874 tokens
    └ .claude/rules/do-not-touch.md: 997 tokens
    ```
    `AGENTS.md` завантажився через імпорт `@AGENTS.md` у `CLAUDE.md`;
    `do-not-touch.md` (без `paths`) — з першого повідомлення.
  - «Не відкриваючи файлів, перелічи правила в контексті» → агент назвав 6 ключових
    правил з `AGENTS.md`, зміст `do-not-touch.md` і примітки з `CLAUDE.md` і сам
    зазначив: «**Не завантажені** (потребують читання `.ts`-файлів):
    `.claude/rules/architecture.md`, `.claude/rules/conventions.md`».
  - Після читання `slack-notify.ts` агент відповів «Також підтягнулися два додаткові
    правила» і переказав їх, зокрема факти, яких немає ні в `AGENTS.md`, ні в
    `CLAUDE.md`, ні в прочитаному файлі: `redact` у публічному API ядра і «рівно три
    зміни» для нової інтеграції (є лише в `architecture.md`), «лише ім'я, джерело й
    бюджет» у сповіщеннях (лише в `conventions.md`).
  - Спостереження: другий `/context` показав у **Memory files** ті самі три файли.
    Правила з `paths` у Claude Code 2.1.20 додаються до розмови разом із результатом
    `Read` і рахуються в **Messages** (8 → 6.8k токенів), а не в Memory files. Тож
    `/context` підтверджує завантаження бази й безумовного правила, а правила з
    `paths` видно з поведінки агента.
